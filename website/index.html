What the SDK is for

Your pipeline keeps doing the work.

Pipeline Autopsy sits beside the enterprise request path. Add lightweight decorators to the pipeline you already have, then let the collector receive traces asynchronously.

The SDK observes inputs, outputs, timing, and status without changing the business decision. When a run looks suspicious, Autopsy walks the stages in order and separates the origin from everything it affected.

The connector

One install between your pipeline and the evidence.

The Pipeline Autopsy SDK is a small Python connector for sending execution context to the collector without rewriting your business logic.

01
Decorate the steps you care aboutUse @autopsy.trace_step on existing functions and keep the pipeline readable.
02
Wrap one executionContext variables keep claim and execution IDs attached without threading them through every call.
03
Stay safe when the collector is downTrace delivery is best effort. Observability gaps never become business failures.
# install the connector
$ pip install -e ./sdk
# connect once, then trace the run
@autopsy.trace_step("extraction")
